# Analisis Kandidat Jerawat - Pengolahan Citra Digital

Aplikasi Streamlit untuk membaca histogram citra dan mencari KANDIDAT jerawat
dengan metode klasik (grayscale, histogram, enhancement, threshold, morfologi,
contour). Bukan alat diagnosis medis.

## Instalasi
```
pip install -r requirements.txt
```

## Menjalankan
```
streamlit run app.py
```
